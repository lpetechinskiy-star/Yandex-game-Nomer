# Номерной Перекуп

Браузерная игра для Яндекс Игр: крутите цифры и буквы автомобильного номера, собирайте редкие комбинации, продавайте, выполняйте заказы и ставьте номера на машины.

Стек: Vite + TypeScript без фреймворков. Номера рисуются в SVG (`textLength` у каждого символа). Шрифты лежат в проекте.

## Команды

| Команда | Что делает |
|---|---|
| `npm install` | установить зависимости |
| `npm run dev` | локальная игра на http://localhost:5173 (SDK заменён mock) |
| `npm test` | тесты (vitest): оценка редкости, игровые действия, реклама |
| `npm run build` | проверка типов и сборка в `dist/` |
| `npm run zip` | архив `build/nomernoy-perekup.zip` для консоли Яндекс Игр; падает, если в сборке есть внешние ссылки |
| `npm run zip:serve` | распаковать архив в `.zip-check/` и открыть на http://localhost:4174 — проверка архива без Vite |
| `npm run cars:placeholders` | перерисовать заглушки машин в `public/cars/` |

Параметры адреса для локальной проверки: `?lang=en` — английский, `?guest` — игрок не залогинен, `?plates` (только `npm run dev`) — ползунки для подбора места номера на машине в гараже.

## Структура

```
src/config/   все числа: экономика, редкость, страны и регионы, машины, заказы, рулетка, бонусы, ранги
src/core/     логика без DOM: генерация номеров, evaluate, цены, заказы, состояние, сохранение
src/ui/       оболочка, страницы (src/ui/pages), SVG-номера, звук, эффекты, стили
src/sdk/      Platform: yandex.ts (Yandex Games SDK v2) и mock.ts; пауза, частота рекламы
src/i18n/     тексты ru и en (en типизирован по ключам ru — пропущенный перевод не скомпилируется)
tests/        vitest
public/cars/  картинки машин
reference/    прототип (без картинок машин — они из чужой игры)
```

## Машины

Каждая машина — картинка в `public/cars/` и запись в `src/config/cars.ts`:

```ts
{ id: "merc", img: "cars/mercedes-e.svg", cls: 2.2, plateX: 50, plateY: 69.6, plateW: 15 }
```

`plateX`, `plateY` — центр номера в процентах от ширины и высоты картинки, `plateW` — ширина европейского номера в процентах от ширины картинки (номер США автоматически уже). Сейчас в `public/cars/` нарисованные заглушки (вид сзади). Чтобы поставить настоящую картинку: положите файл в `public/cars/`, поменяйте `img`, откройте `npm run dev` → `/?plates` → Гараж, подвиньте ползунки и скопируйте готовую строку в конфиг.

## Yandex Games SDK

- `index.html` подключает `<script src="/sdk.js">`. На площадке файл отдаёт Яндекс; локально — пустая заглушка, и игра включает mock (реклама — окно на 3 секунды).
- `YaGames.init()` → загрузка сохранения → отрисовка → `LoadingAPI.ready()` после загрузки шрифтов.
- `GameplayAPI.start()/stop()`: стоп во время рекламы, при сворачивании вкладки и по событию `game_api_pause`; звук на паузе выключается.
- Реклама за вознаграждение: бесплатная прокрутка, ×2 к цене, набор LADA (1 реклама), Mercedes (3 рекламы, +2 500 ₽ за каждую), рулетка (2 рекламы). Награда выдаётся только в `onRewarded`.
- Полноэкранная реклама: после продажи номера и выполнения заказа, не раньше чем через 2 минуты после запуска и не чаще раза в 2 минуты (`TIMERS.fullscreenIntervalMs`).
- Сохранения: `player.setData/getData` для залогиненного игрока (берётся более свежее из облака и localStorage), иначе localStorage.
- Лидерборд `prestige` (очки сезона): `setScore` и `getEntries` на экране рейтинга.
- Оценка: `feedback.canReview` → `requestReview`, +10 000 ₽ один раз, если отзыв отправлен.
- Язык: `environment.i18n.lang` (ru, be, kk, uk, uz → русский, остальное → английский).

### Что настроить в консоли Яндекс Игр

1. Загрузить `build/nomernoy-perekup.zip`.
2. Создать лидерборд с техническим названием **`prestige`** (тип «число», по убыванию).
3. Возрастной рейтинг 6+, языки ru и en.

## Модерация

- Нет внешних ссылок и сторонней рекламы (`npm run zip` это проверяет).
- Без горизонтальной прокрутки на телефоне и ПК, в портретной и альбомной ориентации (на телефоне меню — прокручиваемая полоса сверху).
- Выделение текста, контекстное меню, масштаб щипком/двойным тапом/Ctrl+колесом отключены (`src/ui/guards.ts`, `main.css`).
- Внизу каждой страницы: «6+ · Игра не связана с ГИБДД и МВД России».
